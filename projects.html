Women's Studies History Collective

This is a project I worked on for my Women's Studies course with Dr. Lisa Fine. We studied the history of the Women's Studies program at Michigan State University. WHSC was particularly fun and challenging because we got to use a web publishing platform created for institutions with collections. This meant that the artifacts we came across had to be entered into our system with as much correct and useful metadata as possible. Research involved many trips to the special collections and a lot of time scanning original documents or using talk to text for certain ones to make them easily searchable.

Romance in Color

For my final project in Introduction to Digital Humanities, I was told that I could make a project on anything that pertained to studying culture/media using some of the methods we looked at during the class. Romance in Color was a project I put together analyzing colors of book covers from every romance subgenre. I hypothesized that I would be able to tell what subgenre a book was just buy its color pallette. This project was pretty intense for me becuase I had decided that this was going to be how I learned to code python. Most of the original code was put together with ChatGPT (and many, many hours), I was able to get a moving three dimensional graph by the end. In the end, I learned the structure of what code looks like, how to use github, created a mongoDB of my data set, and that I really enjoyed working on code.

East Lansing Live

This was the main project of my second Digital Humanities course. It was a group project about capturing the history of the live music scene in Lansing and East Lansing from 1995 to 2025. My portion of the site was an embeded leaflet map that contained a searchable database of some of the liver performances that happened in 1995 at the different bars around Grand River Avenue (the street budding up against Michigan State University campus). Creating the leaflet was a difficult process. Initally, all of the data was supposed to go into a Google sheet until plans for the map changed. Adding a database component was going to be hard for Sheets, so I decided to scrap the sheet entirely and start over in python. Luckily, the documentation for Leaflet is amazing because I was able to code much more that semester (the previous semester I started Romance in Color) and learn more things beyond python. For the database, I was able to use a regular JSON file with an extra bit of code that would put the information in the JSON format I specified.
